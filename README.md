## 游戏简介

《千年迟赴：文明灰烬》是一款以叙事为核心的 2D 横版冒险游戏。玩家扮演一位被召唤的勇者，降临到千年后的废墟世界。通过独特的"回溯"机制，玩家可以窥见千年前的盛景，逐步揭开一位圣女默默守护文明的隐秘往事。

游戏采用暗线叙事手法，不直接讲述真相，而是通过环境碎片、NPC对话、回溯场景等元素，让玩家自行拼凑出完整的故事。

## 特色功能

- **时空回溯系统** - 教堂和图书馆进入时自动触发回溯，其他场景按F键触发，窥见千年前的盛景
- **多结局分支** - 5种截然不同的结局，取决于玩家的选择与行动
- **暗线叙事** - 故事隐藏在细节之中，等待玩家自行发掘
- **多场景探索** - 6个精心设计的场景，每个场景都有独特的道具和NPC
- **跳跃解谜** - 场景五设有需要精准跳跃才能到达的隐藏区域

## 编译与运行

### 环境要求

- Qt 6.x (推荐 Qt 6.11 或更高版本)
- C++17 兼容编译器 (MSVC / MinGW / GCC / Clang)
- Qt Creator (可选，推荐)

### 编译步骤

#### 方式一：使用 Qt Creator (推荐)

1. 安装 Qt 6.x 及 Qt Creator
2. 打开 Qt Creator，选择 `文件 -> 打开文件或项目`
3. 选择 `LateMillennium.pro` 文件
4. 配置编译套件(Kit)，选择 Qt 6.x
5. 点击 `构建 -> 构建项目`
6. 运行游戏

#### 方式二：命令行编译

```bash
# 进入项目目录
cd LateMillennium

# 生成 Makefile
qmake LateMillennium.pro

# 编译
make        # Linux/macOS
mingw32-make  # Windows MinGW
nmake       # Windows MSVC

# 运行
./LateMillennium        # Linux/macOS
LateMillennium.exe      # Windows
```

## 游戏操作

| 按键 | 功能 |
|------|------|
| `A` / `←` | 向左移动 |
| `D` / `→` | 向右移动 |
| `W` / `↑` / `Space` | 跳跃 |
| `E` / `Enter` | 交互（与NPC、道具对话） |
| `F` | 时空回溯（每个场景限一次） |
| `H` | 显示/隐藏场景提示 |
| `Esc` | 返回/取消 |

## 游戏剧情

### 故事背景

末日阴霾笼罩大地，人类文明濒临灭绝。千年之前，一位圣女以自身之力维系召唤法阵，等待传说中的勇者降临拯救世界。然而，当勇者终于降临时，却发现世界已是一片废墟——法阵的召唤，似乎迟到了整整一千年。

### 场景概览

1. **破败教堂** - 勇者降临之地，进入时自动回溯，暗示圣女的等待
2. **赛博地下城** - 沉睡千年的地底避难所，幻梦机器可传送至金字塔
3. **沙漠金字塔** - 黄沙掩埋的古老王国，铭文解锁石棺暗道
4. **末日火山** - 浩劫的源头，守剑幽魂两步交互后获得断剑
5. **图书馆秘境** - 进入时自动回溯圣女独白，跳跃台阶发现文明种子
6. **时空闭环** - 终点即是起点，千年布局的真相

### 回溯系统

- **教堂、图书馆**：进入场景时自动触发回溯（纯净背景+对话，暗示故事人物）
- **其他场景**：按 `F` 键触发回溯（每个场景限一次）
- **回溯画面**：纯色背景，无角色、NPC、道具、地砖，只有对话文字

### 结局分支

游戏包含 5 种结局，玩家的选择将决定勇者的命运：

| 结局 | 触发条件 |
|------|----------|
| 文明新生 | 在图书馆秘境使用文明种子 |
| 逆时赴约 | 研究残缺手稿 / 在教堂魔法阵选择回到原来的世界 |
| 幻梦沉沦 | 启动幻梦机器，沉溺于虚假的美好 |
| 枯骨永眠 | 躺入金字塔石棺，陷入永恒的沉眠 |

### 游戏流程

```
开场画面 → 教堂（自动回溯）→ 地下城 → 金字塔 → 火山
    → 图书馆（自动回溯）→ 发现种子 → 传送门回到教堂
    → 魔法阵（新选项：回到原来的世界）
```
