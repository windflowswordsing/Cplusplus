# 千年迟赴 - 游戏工程架构文档

## 一、项目概述

**游戏名称**：千年迟赴 - 文明灰烬与圣女之约
**游戏类型**：2D横版叙事冒险游戏
**开发框架**：Qt 6 (C++)
**核心主题**：穿越千年的文明遗迹探索，揭示末日真相

---

## 五、渲染管线

```
┌─────────────────────────────────────────────────────────────────┐
│                         渲染顺序                                │
├─────────────────────────────────────────────────────────────────┤
│                                                                 │
│  paintEvent() {                                                 │
│      1. 绘制背景色 (scene.bgColor)                              │
│      2. 绘制卷轴背景层 (drawScrollingBg)                        │
│      3. 如果回溯状态:                                           │
│         ├── 绘制回溯背景色                                      │
│         └── 跳过游戏元素                                        │
│      4. 绘制游戏元素:                                           │
│         ├── 地面和平台 (drawPixelGround)                        │
│         ├── 道具 (drawProps)                                    │
│         ├── NPC (drawNpcs)                                      │
│         └── 玩家 (drawPlayer)                                   │
│      5. 绘制UI层:                                               │
│         ├── HUD (drawHUD)                                       │
│         ├── 对话框 (drawDialog)                                 │
│         └── 立绘 (勇者/国王/幽灵)                               │
│      6. 绘制结局画面 (如果状态为Ending)                         │
│  }                                                              │
│                                                                 │
└─────────────────────────────────────────────────────────────────┘
```
